SelfControl

A Firefox add-on that puts strict, activity-aware time limits on websites. The clock only runs while you are actually consuming the site — YouTube counts while a video is playing, not while it sits paused.

Install

Self-distributed and signed by Mozilla. Download the latest .xpi and open it with Firefox, or use about:addons → gear → Install Add-on From File.

Latest release

Updates after that are automatic, via updates.json.

How it counts

  • While playing — time accrues only while a tab is producing sound, including in the background. Muted hover-previews do not count.
  • While focused — time accrues only while the tab is the focused one. Switch to another app and the clock stops.

Budgets run over a rolling window, so time comes back gradually rather than resetting on the hour.
